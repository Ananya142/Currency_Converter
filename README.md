## 💱 Currency Converter

A simple, responsive Currency Converter built using **HTML**, **CSS**, and **JavaScript**. It fetches real-time currency exchange rates from the [ExchangeRate-API](https://www.exchangerate-api.com/) to convert any amount from one currency to another.


### 📁 Project Structure

```
├── index.html        # Main HTML structure
├── style.css         # Styling for the application
├── script.js         # JavaScript logic (API calls, DOM updates)
└── README.md         # Project documentation
```

### ⚙️ Features

* ✅ Real-time exchange rates using ExchangeRate-API
* 🌍 Wide range of currencies supported
* 💻 Responsive and clean user interface
* 🧪 Input validation and error handling



### 🔧 Getting Started

#### 1. Clone the repository:

```bash
git clone https://github.com/your-username/currency-converter.git
cd currency-converter
```

#### 2. Open `index.html` in your browser

No server setup is required! It's a static frontend project.


### 🔑 API Key Setup

1. Get a free API key from [https://www.exchangerate-api.com/](https://www.exchangerate-api.com/).
2. Replace the key in `script.js`:

```js
const API_KEY = 'your-api-key-here';
```
